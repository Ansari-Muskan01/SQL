-- 1. What is Data?

-- Definition: Data is a collection of raw facts and information that can be stored, processed, and 
-- analyzed to generate meaningful information.

-- In Simple words: Data means raw facts or values that describe something.

-- 2. What is a Database?

-- Definition: A database is an organized collection of related data that can be stored, accessed, managed, 
-- and retrieved efficiently.

-- In Simple Words: A database is a place where we store and organize data so that we can easily access and manage it.
--------------------------------------------------------------------------------------------------------------
-- 3. What is DBMS?
-- DBMS = Database Management System

-- Definition: A Database Management System (DBMS) is software used to create, store, organize, manage, update,
-- and retrieve data from databases.

-- In Simple Words : A DBMS is software that helps us manage databases and the data stored inside them.

-- What can a DBMS do?

-- A DBMS allows us to:
-- Create databases
-- Create tables
-- Insert data
-- Update data
-- Delete data
-- Retrieve data
-- Manage database structure

-- Banking Example : 
-- Instead of manually managing thousands of customer records, a bank can use a DBMS to efficiently store 
-- and manage customer information.
------------------------------------------------------------------------------------------------------------------

-- 4. What is RDBMS?
-- RDBMS = Relational Database Management System

-- Definition: A RDBMS is a type of DBMS that stores data in tables and allows relationships to be established 
-- between related tables.

-- In Simple Words : A RDBMS stores data in tables and connects related tables using relationships.

-- For example:

-- Customers
--      ↓
-- Accounts

-- Banking Example

-- Customers                   -- Accounts                               

-- | Cust_ID | Name  |     | AccountID | Cust_ID    | Balance |    
-- | --------| ----- |     | --------: | ---------  | ------: |
-- |  101    | Rahul |     |      1001 |        101 |   50000 |
-- |  102    | Priya |     |      1002 |        102 |   75000 |

-- Here:
-- Customers.Cust_ID
--         ↓
-- Accounts.Cust_ID          (The CustomerID connects the two tables.)
-------------------------------------------------------------------------------------------------------------------
-- 5. DBMS vs RDBMS

-- | DBMS                                     | RDBMS                                           |
-- | ---------------------------------------- | ----------------------------------------------- |
-- | Database Management System               | Relational Database Management System           |
-- | Manages databases                        | Manages relational databases                    |
-- | May not use relationships between tables | Supports relationships between tables           |
-- | Data can be stored in different forms    | Data is primarily stored in tables              |
-- | Suitable for simpler database systems    | Suitable for structured and large-scale systems |
-- | Example: SQLite can be used as a DBMS    | MySQL, Oracle, PostgreSQL                       |

-- DBMS → Manage data
-- RDBMS → Manage data + relationships between tables
-----------------------------------------------------------------------------------------------------------------
-- 6. What is SQL?
-- SQL = Structured Query Language

-- Definition: SQL is a standard language used to communicate with relational databases to create, store, 
-- retrieve, update, and manage data.

-- In Simple Words : SQL is the language we use to communicate with a database.

-- SQL is used for:
-- Creating databases
-- Creating tables
-- Inserting data
-- Retrieving data
-- Updating data
-- Deleting data
-- Managing database structures

-----------------------------------------------------------------------------------------------------------------


-- 7. SQL vs MySQL
#| SQL                                                                    | MySQL                                                          |
#| --------------------------------------------------------------------   | -------------------------------------------------------------- |
#| SQL stands for Structured Query Language.                              | MySQL is a Relational Database Management System (RDBMS)       |
#| SQL is a language used to communicate with databases.                  | MySQL is software that uses SQL to manage databases.           |
#| SQL defines commands such as `SELECT`, `INSERT`, `UPDATE`, and `DELETE`| MySQL executes these SQL commands and manages the stored data. |
#| SQL itself does not store data.                                        | MySQL stores and manages data in databases and tables.         |
#| SQL can be used with different database systems.                       | MySQL is one specific database system.                         |
#| Example: SELECT * FROM Customers;                                      | MySQL can execute this SQL query on a MySQL database.          |
# SQL = Language
# MySQL = Software that understands and executes that language

-- 8. What is a Table?
-- Definition: A table is a structured collection of related data organized into rows and columns.

-- Customer Table (Sample Table)
-- | CustomerID | FirstName | LastName | Email            | Phone      |
-- | ---------  | --------- | -------- | -----------------| ---------- |
-- |        101 | Rahul     | Sharma   | rahul@gmail.com  | 9876543210 |
-- |        102 | Priya     | Singh    | priya@gmail.com  | 9876543211 |

-- 9. What is a Column?
-- Definition: A column represents a specific attribute or category of data in a table.

# | CustomerID | FirstName | LastName | Email            |
# | ---------  | --------- | -------- | -----------------|
# |        101 | Rahul     | Sharma   | [rahul@gmail.com]|
# |        102 | Priya     | Singh    | [priya@gmail.com]|

-- CustomerID → Column
-- FirstName → Column
-- LastName → Column
-- Email → Column

-- 10. What is a Row?
-- Definition: A row represents a single complete record in a table.

-- | CustomerID | FirstName | LastName | City   |
-- | ---------: | --------- | -------- | ------ |
-- |        101 | Rahul     | Sharma   | Mumbai |
-- |        102 | Priya     | Singh    | Delhi  |

-- First row: 101 | Rahul | Sharma | Mumbai   → This is one complete customer record.

-- Column = What type of information?
-- Row = One complete record


-- 11. What is a Data Type?
-- Definition: A data type defines what kind of value can be stored in a column.

-- Common SQL Data Types
-- | Data Type    | Used For             | Example    |
-- | -------------| -------------------- | -----------|
-- | INT          | Whole numbers        | 101        |
-- | CHAR(n)      | Fixed-length text    | 'India'    |  char(4)   -- A (
-- | VARCHAR(n)   | Variable-length text | 'Rahul'    |  varchar(4)  -- A (1)
-- | DECIMAL(p,s) | Decimal numbers      | 50000.75   |
-- | DATE         | Dates                | 2026-08-10 |


-- CHAR vs VARCHAR

-- | CHAR(n)                           | VARCHAR(n)                             |
-- | --------------------------------- | -------------------------------------- |
-- | Fixed length                      | Variable length                        |
-- | Always uses the defined length    | Uses only the required space           |
-- | Best for values with a fixed size | Best for values with different lengths |
-- | Example: CHAR(10)                 | Example: VARCHAR(50)                   |
